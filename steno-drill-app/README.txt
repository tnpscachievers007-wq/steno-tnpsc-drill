STENO DRILL - offline app folder

1. Go to app.netlify.com/drop (log in free so the site stays permanent).
2. Drag this whole folder (not the zip) onto the page.
3. Open the link on your phone.
   Android Chrome: menu -> Install app / Add to Home screen
   iPhone Safari: Share -> Add to Home Screen
4. Open the app once with internet. After that it works offline.
