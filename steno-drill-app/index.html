📚 Library

Your words, images and audio are only saved in this browser. If you just share this file as-is, whoever opens it will see an empty library. Use this button to make a copy with everything already loaded inside — that copy is safe to send.

Fixing a misalignment: click into the word box, then press Enter where you want to split. The text to the right of the cursor drops down into the next row, and every word below moves down one (the images stay put). Press Backspace with the cursor at the very start of a word box to attach that word to the end of the word above it; every word below moves up one, so the images line up again.

Editing a stroke image: under each image there are buttons to Crop it (drag the box, or draw a new one; you can rotate and auto-trim the white margins), Delete only the image, Copy and Paste an image, shift it up or down a row (up replaces the image above and pulls every image below up one; down leaves this row empty and pushes every image below down one), View it large, or Upload a different file. You can also click an image box and press Ctrl+V (Cmd+V on Mac) to paste a copied image straight into it, hover over it and press Ctrl+V, or drop an image file on it. After you delete or change an image, an Undo button appears for a few seconds. With an image box selected, Delete removes the image and Enter opens the cropper.

Each row has the question on top and the answer below it. Press Enter in the question box to go to the answer box. Press Enter in the answer box to go to the next row.
